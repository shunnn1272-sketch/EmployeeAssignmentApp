# Employee Assignment App

## 概要

作業員を各工程へ配置するための業務支援アプリケーションです。

作業員ごとに作業可能な工程を設定し、各工程に対して作業員を手動または自動で配置できます。

自動配置と手動配置を組み合わせることも可能で、現場の状況に応じた柔軟な作業員配置を行えます。

---

## 使用技術

- C#
- .NET
- Windows Forms
- Entity Framework Core
- LINQ

---

## 主な機能

### 作業員管理

- 作業員の登録
- 作業員の削除
- 作業員一覧の表示
- 作業員ごとの作業可能工程の編集

---

### 工程管理

- 工程の追加
- 工程の削除

---

### 作業員の工程配置

各工程に対して、作業員を配置できます。

- ダブルクリックによる作業員の割り当て、割り当てた作業員の個別クリア
- クリアボタンによるすべての割り当てのクリア
- 自動配置
- 手動配置
- 自動配置と手動配置の組み合わせ

また、工程行を選択すると、その工程で作業可能な作業員だけを作業員リストに表示します。

これにより、作業員のスキルを確認しながら配置できます。

---

### 不在者管理

不在者を管理し、配置対象から除外できます。

- 不在者一覧への作業員の登録
- ダブルクリックによる不在者の割り当て、不在者割り当ての個別クリア
- クリアボタンによる不在者割り当ての全クリア

---

### 自動配置

作業員の作業可能工程や不在状況を考慮し、作業員を自動で各工程へ配置します。

同じメンバーでも毎回同じ配置にならないように配置ロジックにランダム要素を取り入れました。

また、自動配置が成立しない場合は、配置できないことをメッセージで通知します。

これにより、配置後に必要人数を満たしていない状態を見逃しにくくしています。

## 操作方法

### 工程管理
上部メニューの工程をクリックします。
- 工程の新規登録<br>
　追加を選択。追加したい工程名を入力し、追加ボタンをクリック

- 工程の削除<br>
　削除を選択し。削除したい工程名を選択、削除ボタンをクリック

 ### 作業員管理
 上部メニューの作業員をクリックします。
 - 作業員新規登録<br>
   追加を選択。名前を入力し、役職を選択、追加ボタンをクリック<br>
    ※社員コードは自動で決まります。

 - 作業員削除<br>
   削除を選択。社員コード、名前を入力し、削除ボタンをクリック

 - 作業員情報編集<br>
   編集選択。社員コードと名前を入力<br>
   1. 習得済み工程を見たい場合は習得済み一覧をクリック<br>
   2. 作業可能工程を追加したい場合は、追加を選択、工程を選択し、追加ボタンをクリック<br>
   3. 作業可能工程を削除したい場合は、削除を選択、工程を選択し、削除ボタンをクリック<br>

 - 作業員一覧<br>
   一覧を選択すると登録した作業員の一覧を見れます。


### 作業員の配置
- 手動配置
  1. 工程名を選択すると作業員リストに、その工程の作業可能者が表示されます。
  2. 名前をダブルクリックすると選択した工程に作業員が配置されます。<br>
   

- 不在者配置
　不在表をクリックし、作業員リストの中から、不在者を選択します。
   
- 自動配置
  自動配置をクリックすると、空いている工程に作業員が自動で配置されます。<br>
  作業員の不在、配置状態によっては全ての工程に作業員を配置できない場合があります。<br>
  その場合は、配置できない旨をメッセージで表示し、すべての配置がクリアされます。

- 配置のクリア
 　工程に配置された作業員の名前をダブルクリックすると、配置を解除できます。<br>
   クリアボタンを押すと、全ての作業員の配置を解除できます。
